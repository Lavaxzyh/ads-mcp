## 本次分享版验证

验证环境：Windows、Keysight ADS 2025 `610.shp`、匹配的 ADS Python 3.12.2 / PySide2 5.15.10，使用独立任务目录；没有打开或修改原用户工程。

- **201 项单元测试通过**，覆盖既有输入/任务/缓存/隔离等逻辑，新增共享 ADS 路径解析检查。单元测试本身不证明实际原生接口成功。
- 启动独立 MCP 服务，实际注册 **64 个工具**，保留 **49 个上游工具名称**；工具名检查不代表所有工具参数与全部操作逐项回归。
- 使用 `examples/schematic/output_match_short.json` 的公开合成输入，在真实 ADS 中完成 30 元件建图、保存重开、指定变量修改、同请求重放、原生重新提取及有效快照复用。
- 无效实例请求被拒绝，工作区文件清单与 SHA256 保持不变；最终只保留一张目标原理图。
- 本次没有启动 GUI、Momentum、SP 或 HB 求解器；没有将结构验收称为功放性能验收。

公开结构化摘要为 [validation-summary.json](validation-summary.json)。原始日志含本机路径、进程信息和任务输出，不随源码发布。根目录 `release-validation.json` 记录发布代码哈希与相对证据路径。

安装测试依赖后，从仓库运行：

```powershell
& '.venv/Scripts/python.exe' -B tools/run_unit_tests.py
```

原生复核必须有匹配的 ADS 安装与许可，并使用新的独立任务目录。调用步骤及短请求见 [单原理图工作流](../SINGLE-SCHEMATIC.zh-CN.md)；合成样例的目录、参考面与电气参数须明确核对，不能当作真实 PA 初值。

## 历史线性 SP 与效率证据

以下数据来自 `.2` 的本地独立验证记录，本次发布只核对并提取摘要，没有重新跑完这套 SP 测试矩阵：

- 25 项真实 ADS 流程检查通过，包括任务/修订冲突、重复请求、无写入拦截、断开重连后继续观察原任务、缓存命中和强制重算。
- 18 对相同条件的网表与结构比对完全一致。
- 串联 50 Ω / 75 Ω 电阻的 SP 与独立解析结果一致；同条件强制重算的最大复数 S 差为 0（3 个频点）。这不证明有源器件、非线性 HB 或实测表现。

同机、相同输入、相同验收标准，比较“输入已经准备好后的建图＋两次修改＋一次错误拦截”。每种条件各 3 次，时长为脚本观测区间，包含客户端/服务启动及相应操作；warm 表示任务步骤共用同一专用服务，cold 表示步骤重复启动服务，并不代表清空 OS 磁盘缓存。

| 指标 | 基线 `.1` | 效率版 `.2` |
|---|---:|---:|
| 共用服务中位数（秒） | 9.524 | 8.125 |
| 共用服务最小–最大（秒） | 9.385–9.656 | 7.842–9.087 |
| 重复启动服务中位数（秒） | 24.957 | 25.580 |
| 每次任务 MCP 业务调用数 | 7 | 4 |
| 共用服务返回文本中位数（UTF-8 字节） | 5,525 | 2,158 |
| 完整工具目录（UTF-8 字节） | 75,275 | 75,438 |
| 实际模型 token | 未观测 | 未观测 |

冷启动没有改善，完整工具目录没有缩小。以上不是从工程要求到设计完成的全过程计时，不包含此前资料阅读、模型思考、人工决策或真实功放优化。不能由调用数或字节数下降推算同百分比的设计时间/token 降幅。公开合成样例已更换电气参数，不冒充这组历史基准输入。

## 历史 EM / GUI 证据

`.1` 的独立 ADS 2025 案例覆盖 MLIN 原生 Layout/PSN、lookalike、Momentum 两端口求解、原生 emModel/MomCmpt、串 R/并 C 联合仿真、单变量单目标 Gradient 优化、未缓存尺寸重新求解及本任务 GUI 管理。范围为平面 Momentum microwave、两端口实数 50 Ω、线性 SP；几何、端口、完整复数 S 和结果来源分别核验。

当前发布没有重跑完整 EM/GUI 矩阵。参数、调用顺序及已知限制见 [EM-WORKFLOW.zh-CN.md](../EM-WORKFLOW.zh-CN.md)。上游公开工程沿用作者的出处与验证环境，不因被保留在此仓库而视为已在 ADS 2025 逐一重测。

## 仍未覆盖

- ADS 2027 全量回归、任意第三方 PDK / 封装模型 / 用户工程。
- 多端口、差分、复杂多层过孔、非 50 Ω 原生 EM 自动测试台；大规模多变量/多目标 EM 优化。
- 任意已打开的用户 GUI 会话接管、强制取消与未经授权的模型下载。
- 将 EM 联合仿真测试链扩展成任意有源 PA/HB；已有专门 HB 复核接口仍要求支持的模板、模型和端接条件。
- 完整 RF 设计时间、真实云模型 token 消耗，以及制造和实测性能。

源码存在、静态检查、结构验收、线性 SP、非线性 HB 与实测必须分别报告。原工程保持只读，样例条件不能静默套用到新任务。
