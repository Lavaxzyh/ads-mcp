1. headless 与 GUI 的原生修改入口统一持有工作区 `edit_guard`，检查其他客户端留下的持久求解预留。

## SP 算例及数值核对

从 ADS 原生原理图生成双端口网表，两端口参考阻抗均为 50 Ω，中间串联 125 Ω 电阻。频点为 1、1.5、2 GHz。

解析解为 `S11 = S22 = 125/225 = 5/9`、`S21 = S12 = 100/225 = 4/9`；端口 2 接 50 Ω 时，端口 1 输入阻抗为 175 Ω。

- 全部频点和完整复数 S 矩阵对解析解的最大绝对误差：`1.67e-16`。
- 输入阻抗对 175 Ω 的最大误差：`2.85e-14 Ω` 以下。
- 原网表哈希在任务结束时保持不变，任务报告一次原生求解尝试。

初始测试夹具的几何连接曾导致端口短路，求解器正确拒绝。修正测试夹具并在新输出目录重算后取得上述通过结果；失败尝试保留在本地，不计入通过证据。
